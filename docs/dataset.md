# PCB对话与操作样本规范草案

## 一个样本不是一张截图

最小单元是一个边界明确的任务或操作回合：任务要求、执行前状态、用户授权、方案、实际差异、执行后状态、检查结果和反馈。一次长会话可以形成多个回合，回合之间保留父子关系。

不采集模型私有思维链；记录可审查的任务解释、方案摘要、公开答复、工具操作及证据。

## 建议记录

| 类别 | 内容 |
|---|---|
| 任务 | 布局、驱动回路、采样、电源铺铜、网表修复等任务类型和验收目标 |
| 板卡条件 | 板框、铜层、器件/封装/引脚、网表、规则、制造与工况；未知值用null并保留单位 |
| 授权 | 可移动、可布线、可改网、禁止删件等当前范围及用户授权来源 |
| 前后状态 | 原生文件引用/哈希、规范化几何与网络状态、CAD/扩展版本 |
| 操作 | 计划与实际执行分开，包含对象标识、参数、差异、失败和回滚记录 |
| 检查 | DRC类型/规则/对象、网络检查、保护项检查、工程审核及实测证据 |
| 人工反馈 | 接受、拒绝、修改；反馈理由与采用的最终版本 |
| 来源权限 | 作者/来源、文件和数据许可、是否能公开、是否可用于检索、是否可用于训练 |

## 标签不能互相代替

- 流程状态：候选、写入前已阻断、已执行、已撤回、已接受。写入前被保护器拦截不算撤回。
- CAD检查：未检查、失败、所选检查通过、完整约束检查通过。
- 工程审核：待审核、审核通过、存在未解决问题。
- 实板验证：无实板、已打样、已上电、限定工况实测；附证据及工况。

用户点击“接受”、DRC通过和电机实测可用是三个不同层面的证据，不能用一个success布尔值概括。

## 负样本同样重要

以下为概括性的案例类型，不包含真实工程或聊天原文：

- 选错工程版本或功率拓扑，生成了与任务不符的副本；应标为任务范围/版本识别失败，而非成功布局。
- 布线路径降低连接错误，却切断电源铜岛；整体质量不合格。
- 人工移动器件导致写入前状态失效，检查器成功阻断覆盖；这是流程保护成功，不是布线成功。
- 栅极网络定义修复正确，未连接报告反而增加；局部网表任务通过，整板仍未完成。
- 某个局部搜索未找到路径；只能表示本方法未找到，不能标成该板无解。

失败方案不进入“可直接复用的正确电路”索引；可进入排错案例或经审核的偏好数据。回滚之后被删除的候选仍保留为明确的失败轨迹。

## 投稿与检索

本地采集默认不上传。公开工程、公开对话、公开脱敏摘要和参与训练分别设置权限；不给用户把全部工程上传的压力。发布前排除帐号、文件路径、令牌、客户或第三方未授权资料。

投稿先进入待审区，检查格式、来源、许可、授权、前后状态对应和证据完整性。再由自动检查和人工审核筛选；不能用“参与人数”替代样本质量。

案例检索必须匹配约束：层数、拓扑、负载类型、已知电流/铜厚、CAD能力等。旧案例的精确坐标和脚本不是可跨工程重放的模板。

## 用于训练前的额外要求

训练权限、可用许可及质量审核均满足，才允许进入某一训练数据版本。训练/验证/测试按项目族或同源设计分组，避免同一块板的相邻快照落在不同集合中，造成虚高评测。

保留一组不参与训练的评测工程，固定规则和任务边界；比较基础模型、检索辅助模型、改进工具与训练后模型的效果，单独归因。发布模型版本时一并说明数据版本、评测范围和已知限制。

## 首版不承诺

不承诺上传一个样本就自动更新模型；不承诺用户越多性能必然提升；不承诺普通DRC代表电气、EMC、热或制造全部通过。
