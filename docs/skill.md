# 使用PCBLoop Skill

PCBLoop现在有一个可以安装的**工作流程Skill**：[`skills/pcbloop/SKILL.md`](../skills/pcbloop/SKILL.md)。它从人机PCB协作中提炼执行逻辑，不包含真实板卡、私人对话、历史UUID或可重放的旧布线脚本。

Skill负责约束和执行方法；实际读写CAD仍需要单独可用的连接器/API或UI工具。安装Skill不会获得CAD权限、接通桥接服务或自动上传样本，也不会训练模型。

## 安装到Codex

在仓库目录执行（仅Python标准库，无需开发依赖）：

```bash
python tools/install_skill.py
```

默认安装到`$CODEX_HOME/skills/pcbloop`；未设置`CODEX_HOME`时使用`~/.codex/skills/pcbloop`。自定义位置可以用：

```bash
python tools/install_skill.py --skills-dir ./local-skills
```

自定义位置仅用于复制/测试，不会自动加入Codex发现目录。安装器不执行CAD代码、不改应用配置；已有完全相同版本则不重写，有不同版本/个人修改则拒绝覆盖。升级时先将旧目录手动备份到技能目录之外，再安装新版本。

也可以把仓库中的`skills/pcbloop`整个文件夹手动复制到个人技能目录。不要只复制`SKILL.md`：它引用同文件夹下的参考资料和模板。第三方宿主能否识别该格式，需要按宿主说明确认。

安装后新建一个Codex对话，使用`$pcbloop`显式调用；也保留正常自动发现，不要求每次复制长提示词。

## 以后自己使用

新项目：

```text
使用 $pcbloop。先读取我的嘉立创工程，核对器件版本、引脚网络、板框、
叠层和实际DRC。保留元件型号、封装、网络和已有线路，
允许布局及铜图优化。先说明实际读取结果，再在授权范围内执行。
```

只做准备，自己布局布线：

```text
使用 $pcbloop。这次只整理指定版本器件并核对网络和飞线显示，
保留我的原板布局，不布线、不自动更新原理图到PCB。
先确认目标PCB和器件版本；把需要授权修复的差异单独列出。
```

跨对话续接：

```text
使用 $pcbloop。继续指定工程，先读工程目录的三份最新交接报告并核现场。
仅继续未完成模块，旧apply和坐标不能重放。联合规划后连续推进多个模块，
每模块保存和检查；预算收尾优先保存与完整交接。
```

这些示例是新任务的输入，不继承任何历史板卡的授权。请提供实际工程目录或当前目标，让AI能查到报告和CAD状态。

## 本次对话提炼的执行逻辑

| 观察到的问题 | 通用执行逻辑 |
|---|---|
| 旧版/新版器件数量或拓扑混淆 | 先确认目标版本、BOM和真实引脚网，再准备或修改 |
| 在线人工工作超出旧快照 | 当前值守卫；重新核现场，不能重放旧apply |
| 每次只完成很小任务消耗上下文 | 联合规划、连续多模块、模块检查点、批末统一交接 |
| SDK改ID、拆线或重置桥接属性 | 用实际几何/网络/原连接组核验，特殊属性单独保护 |
| DRC下降掩盖断网/功率瓶颈 | 分型比较DRC并独立检查网络、参考面、铜颈和回流 |
| 用户只要前期准备，AI继续布线 | 按最新范围选择模式，交还用户完成后续设计 |
| 工况未知导致乱猜规则或停止所有工作 | 记录未知项，查证原版与资料，推进有依据的局部工作，限制额定结论 |
| 长会话结束后无法恢复 | 原生保存、三份报告和自包含续接提示词 |

这些是给AI的执行要求，不是已经实现的自动守卫。Skill格式/安装测试不证明CAD结果安全；真实工程仍需实际检查。

## 当前验证范围

格式按Skill Creator工具检查；安装器测试覆盖完整复制、重复安装、保留个人修改和拒绝非法包。尚未完成多模型/多板卡的独立行为评测；不能把文档校验当成自动布线或实板验证。

## 文件职责

- `SKILL.md`：任务选择、现场基线、批次循环、失败处理、报告和数据边界。
- `references/easyeda.md`：仅嘉立创连接、单位、Fill/NetTie、对象ID和飞线显示相关任务时读取。
- `references/power-and-signals.md`：功率/驱动/Kelvin与多地网络相关任务时读取。
- `references/checkpoint-and-handoff.md`：保存、A～F报告和续接。
- `assets/project-brief.template.md`：本地项目简报，不作为强制填表门槛。

原有JSON Schema与验证工具仍在仓库中，负责样本元数据检查；它们不是Skill执行CAD的前置服务器，也不需要随Skill复制到个人目录。

## 可选本地经验库

仓库工具现在提供案例记录、审核、检索和反馈。用户启用后，Skill按`references/case-memory.md`接入；需要保留源码仓库及Python依赖，独立Skill包不包含数据库程序。

它不会自动批准真实案例、上传数据或训练模型。演示、权限、证据和社区服务的后续实现见[本地经验库指南](case-memory.md)。
